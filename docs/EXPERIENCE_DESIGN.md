## 1. デザイン原則 — "Sound is Light"(音は光である)

現在のアプリには2つの美学が同居している: ビジョン文書の「カラフルなゲーム的報酬」と、実装済みの「Divine Monochrome(黒・白・Cinzel・神聖幾何学)」。**Divine Monochrome を基調として貫き、色ではなく「光」を報酬にする。**

1. **暗黒が既定、光が事件。** 世界は限りなく黒に近い。音が鳴る瞬間だけ、鳴った場所が発光する。ブルームがその光を空間に滲ませる。プレイヤーは「音を見る」。
2. **色は稀少資源。** 通常時は白〜月光色のみ。色が現れるのは (a) コンボの階梯(5/10/20)、(b) Flow 状態、(c) Perfect Run のみ。稀少だから効く。パレットは深藍 #0A0A0F / 月光 #E8E6E0 / ターコイズ #00BFA6 / 金 #D4AF37 の4色で完結。
3. **すべての動きは呼吸する。** 4〜6秒周期の正弦波(人間の安静時呼吸)を全システムの共通クロックにする: モジュールの微発光、ドローンのLFO、カメラの浮遊、UIの明滅。周期を共有することで「世界がひとつの生き物」に感じられる。
4. **UIは消えるためにある。** 30秒無操作でオーバーレイUIをフェードアウト(ポインタ移動で復帰)。残るのはキャンバスと音だけ。
5. **60fps は美学の一部。** カクつきは催眠を破る。エフェクト追加は常にフレーム予算(モバイル 16ms)と引き換えに評価する。

## 2. AUDIO — 瞑想的サウンドスケープ(担当: Fable 本体)

### 2.1 Ambient Drone System(常時鳴る「場」)
- 3レイヤー構成(vision準拠、ただしDivine調に調律):
  - **Ground**: 65.41Hz (C2) + 130.81Hz、サイン、-28dB。ほぼ触覚的な低音
  - **Pad**: 261.63Hz + 392Hz + 523.25Hz(C-G-C、完全五度)、三角波、-34dB、ローパス 800Hz
  - **Air**: 1046.5Hz + 1568Hz、サイン、-44dB、ゆらぎ大
- 各レイヤーに 0.08〜0.2Hz の LFO(音量・フィルタ)。**呼吸周期(5s)と整数比**にする
- 衝突時: 該当レイヤーのゲインが +3dB まで 200ms で持ち上がり、4s かけて戻る(「場が応える」)
- ミュート・マスターチェーンに完全従属。初回ジェスチャ後にフェードイン(8s)
- コンボ 10+ で第4レイヤー(倍音キラキラ)が静かに追加、コンボ途切れで退場

### 2.2 Harmonic Resonance Chain(五度圏の旅)
- Phase 3 で修復済みの `HarmonyEngine` を**有効化**
- 衝突音のピッチ選択を「現在のキー」のペンタトニックに拘束(現在は毎回ランダム4オクターブ — 音楽的な芯がない)
- 8衝突ごとに五度圏を1歩進む: C → G → D → …。ドローンの Pad レイヤーも 2s のクロスフェードで追従(**世界全体が転調する**)
- 転調の瞬間、後述の Aurora パルスを1回発火(音と光の同期イベント)

### 2.3 Velocity → 音色の明るさ
- 現状: 速度→音量のみ。追加: 速度→ローパスカットオフ(soft hit = こもった優しい音、hard hit = 開いた輝く音)。物理と音の因果が「聞こえる」ようになる

### 2.4 The Silence(静寂の設計)
- 全マーブル消滅から2秒: ドローンの Air レイヤーだけ残して他を -12dB
- 次のマーブル投下の最初の衝突は リバーブ send 最大で鳴る(「静寂を破る一撃」)

### 2.5 Binaural Mode(オプション)
- UIトグル: L=220Hz / R=224Hz(4Hz Theta)、-38dB でドローンに混合。ヘッドフォン推奨の注記

## 3. VISUAL — WebGL ポストプロセッシングによる視覚的催眠(担当: Opus 実装 / Fable 設計・レビュー)

### 3.1 Postprocessing パイプライン(新規依存: `@react-three/postprocessing` + `postprocessing`)
```
EffectComposer:
  Bloom        — luminanceThreshold 0.7, intensity ~0.9, mipmapBlur(低コスト)
  Vignette     — darkness 0.55(視線を中央へ)
  Noise        — opacity 0.015(フィルムグレイン、黒の階調を救う)
```
- ChromaticAberration は**使わない**(瞑想の対極)。DoF も不採用(モバイル予算)
- Bloom は emissive 駆動: ヒット時 `emissiveIntensity` を 0.1→2.5 に振って 300ms で減衰(既存 useHitFlash を拡張)。**光は音の残響と同じ減衰曲線**にする
- モバイル(dpr<1.5 or 幅<768): Bloom 解像度半減、Noise 無効

### 3.2 Marble = 光の粒
- マーブルの emissive を常時 1.2(ブルームで「光の玉」化)。物理は不変
- **ParticleTrail を接続**(実装済み・未マウント資産): ライブ座標は Phase 2 の position ref から。加算合成・0.8s フェード。マーブルが「彗星」になる
- 静止検出→フェードアウト消滅(現状の瞬間消滅を置換): scale+opacity 1s、消滅時に上方向へ粒子が霧散(「昇天」— Divine の語彙で完了を演出)

### 3.3 モジュールの呼吸
- 全モジュールの `emissiveIntensity` を 0.06〜0.14、周期5s(共通呼吸クロック `useBreath()` フック)で明滅。位相はモジュール位置でずらす(波が空間を渡る)

### 3.4 Aurora パルス(転調イベント)
- 五度圏が進む瞬間: 地面に半径30の円形波(shader またはリング×加算合成)が1回走る、ドローンが持ち上がる、Bloom intensity が 1.5s だけ +0.4
- 「8回叩くと世界が応える」— リズムの報酬

### 3.5 実装済み資産の接続
- `ComboDisplay` / `PerfectRunIndicator` / `CompletionCelebration`: マウントし、店 (store) セレクタ駆動に(Phase 4 で準備済み)。ただし**表示言語を Divine 調に統一**: 「5x COMBO!」→ ローマ数字「V」+ 細いリング、金色は 20+ のみ
- `CameraFlow`: ライブ座標追跡で書き直し(Phase 2 で座標基盤済み)。**既定はOFF**、UIトグル「Follow」で有効。追従は lerp 0.8s、呼吸由来の浮遊のみ常時適用(振幅0.3)

### 3.6 環境
- 星屑: 200点の `<Points>` を1ドローコールで(現在の4球体を置換)。視差でわずかに回転(0.05deg/s)
- 地面反射は維持(すでに美しい)。ContactShadows は Bloom 導入後に再評価(光源が動的になるため)

## 4. UI/UX — 消えるインターフェース(担当: Sonnet 実装)

### 4.1 Presence システム
- 30s 無操作 → オーバーレイ(操作パネル・モジュール選択・ヘルプ)が opacity 0 へ 2s フェード。ポインタ移動/キー入力で 300ms 復帰
- フェード中もキーボードは全機能(1-8/Space/M/D/L/C/H/ESC)

### 4.2 情報の階層
- 左下ヘルプカードは初回のみ自動表示、以降 H。スコア/コンボの数値UIは**出さない**(3D空間内の ComboDisplay が唯一の表示 — 画面をHUD化しない)
- セッション終了時(ESC)にだけ、ランディングに「今回: 衝突 n・最大コンボ n・到達キー」を1行、Cinzel で

### 4.3 モバイル
- タッチ: タップ=配置/投下(既存)、2本指ドラッグ=カメラ(OrbitControls標準)
- 下部モジュールバーはスワイプ可能な1行に。44px タッチターゲット確保

### 4.4 音の可視化としてのUI
- ミュートボタン: 再生中はアイコンが音量に合わせて 2% スケール脈動(Tone.Meter、20fps 上限、UI表示時のみ)

## 5. バランスと検証

| 軸 | 目標 | 計測 |
|---|---|---|
| フレーム | デスクトップ 60fps / モバイル想定 30fps+ | Playwright + `requestAnimationFrame` 計測スクリプト |
| 音圧 | マスターで -6dBFS 超えない(リミッター前) | 連打テスト + Meter |
| 静寂比 | 無操作時、ドローンのみ・視覚は呼吸のみ | 目視 |
| 初見動線 | Enter→初マーブル→初音まで 10 秒以内に迷わない | 手動 |

## 6. 実装順序(Phase 5 内サブフェーズ)

1. **5A 音の魂**(Fable): ドローン + 五度圏有効化 + velocity→明るさ + Silence。音が完成してから光を合わせる
2. **5B 光**(Opus): postprocessing 導入 → hit bloom → trail → 呼吸 → Aurora → 星屑
3. **5C 消えるUI**(Sonnet): Presence、ComboDisplay 群マウント、モバイル、セッションサマリ
4. **5D 調律**(Fable): 全系を通した音量/光量/周期の最終バランス、60fps 検証、`/code-review`

各サブフェーズ末に lint/tsc/test/build + ブラウザ検証。コミットはサブフェーズ単位。
