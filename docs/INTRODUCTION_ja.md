# Pythagora Synth - はじめに

**物理 × 音楽 × 瞑想 — ブラウザで動くインタラクティブ・シンセサイザー**

---

## Pythagora Synth とは？

Pythagora Synth は、**物理シミュレーションとモジュラーシンセサイザーを融合**させた、ブラウザベースのインタラクティブ音楽楽器です。

ユーザーがビー玉（マーブル）を落とすと、3D空間に配置されたモジュール（バンパー、チャイム、ベルなど）に衝突し、その衝撃が美しいシンセサイザーの音色に変換されます。ピタゴラスイッチのような連鎖反応を通じて、偶然性と物理法則が織りなすアンビエントミュージックが自然に生まれます。

---

## コンセプト

```
  マーブル（物理）
       ↓ 重力で落下
  モジュール（衝突検知）
       ↓ SynthBridge が変換
  音色生成（Tone.js）
       ↓ エフェクト適用
  リバーブ・ディレイ・ハーモニー
```

物理エンジン（Matter.js）がリアルなマーブルの挙動を計算し、衝突イベントをオーディオエンジン（Tone.js）に橋渡しすることで、**触れる音楽体験**を実現しています。

## 主な特徴

### 1. モジュラー・シンセシス

キャンバス上に自由にモジュールを配置できます。各モジュールは異なる音響特性を持っています。

| モジュール | 役割 | 音の特徴 |
|-----------|------|---------|
| **Ramp** | マーブルの誘導路 | 水琴窟（すいきんくつ）のような余韻 |
| **Bumper** | 衝突トリガー | パーカッシブなアタック音 |
| **Chime** | メロディ要素 | クリスタルのような澄んだ音色 |
| **Bell** | 周波数生成 | 深い共鳴を持つベル音 |
| **Spinner** | 回転要素 | 回転に連動した持続音 |
| **Funnel** | 重力井戸 | 収束するグリッサンド |
| **Seesaw** | バランス要素 | 揺れに応じた音程変化 |
| **Gear** | 機械回転 | メカニカルなリズム |

### 2. ヒーリング周波数

科学的に研究された周波数をプリセットとして搭載しています。

- **528Hz（ソルフェジオ）** — ストレス軽減、"愛の周波数"
- **432Hz（自然律）** — リラクゼーション、自然な調律
- **7.83Hz（シューマン共振）** — グラウンディング、"地球の周波数"
- **40Hz（ガンマ波）** — 認知機能の向上

> 注：これらはウェルネスを目的としたものであり、医療行為ではありません。

### 3. 3D ビジュアライゼーション

Three.js（React Three Fiber）によるリアルタイム3Dレンダリングで、マーブルの軌跡、衝突時の波紋エフェクト、ブルームやグロウによる幻想的な空間を描画します。ランディングページには「フラワー・オブ・ライフ」や「メタトロンの立方体」など、神聖幾何学のモチーフが散りばめられています。

### 4. リアルタイムコラボレーション

Supabase のリアルタイムサブスクリプションにより、複数のユーザーが同時にパッチを編集し、音楽を共同制作できます。

### 5. パッチの保存と共有

作成したモジュール配置（パッチ）をクラウドに保存し、URLで共有できます。

## クイックスタート

### 前提条件

- Node.js 18 以上
- pnpm

### セットアップ

```bash
# リポジトリのクローン
git clone <repository-url>
cd pythagora

# 依存関係のインストール
pnpm install

# 環境変数の設定
cp .env.example .env
# .env を編集して Supabase / Stripe の認証情報を入力

# 開発サーバーの起動
pnpm dev
```

ブラウザで `http://localhost:5173` にアクセスすると、Pythagora Synth が起動します。

## 遊び方

1. **モジュールを配置する** — サイドバーからモジュール（Ramp, Bumper, Chime など）を選択し、キャンバスに配置します。
2. **マーブルを落とす** — マーブルを追加して重力に任せます。
3. **衝突を楽しむ** — マーブルがモジュールにぶつかるたびに、物理パラメータに応じた音色が生成されます。
4. **パラメータを調整する** — 周波数、リバーブ、ディレイなどをリアルタイムで変更できます。
5. **パッチを保存する** — 気に入った配置を保存し、後から呼び出したり共有したりできます。
