## 🎵 AUDIO REVOLUTION - 音の心地よさ・催眠効果

### 1. **Ambient Drone System** (常時再生される背景音)
```
- 528Hz Solfeggio 周波数を基調としたドローン
- 複数のレイヤーで構成:
  - Layer 1: Deep Bass (65Hz - 130Hz)
  - Layer 2: Harmonic Pad (261Hz - 528Hz)
  - Layer 3: Ethereal Texture (高周波の微細な動き)
- LFOでゆっくりとした変化をつける (0.1Hz - 0.5Hz)
- 衝突に応じてレイヤーが一時的に強化
```

### 2. **Harmonic Resonance Chain** (和音の連鎖反応)
```
- 衝突すると単音ではなく、和音が発生
- 五度圏 (Circle of Fifths) に沿って進行
- 例: C → G → D → A → E → B → F# → C#
- マーブルが進むほど音楽的に展開
```

### 3. **Reverb Tail System** (残響の蓄積)
```
- Large Hall Reverb (decay: 8-15秒)
- 衝突音が積み重なり、空間的な厚みを作る
- 静寂な瞬間とのコントラストで催眠効果
```

### 4. **Binaural Beats Mode** (両耳周波数差)
```
- 左耳: 440Hz
- 右耳: 444Hz
- 脳波: 4Hz (Theta波 - リラックス・創造性)
- 切り替え可能なモード
```

### 5. **Procedural Melody Generator**
```
- 衝突パターンから旋律を生成
- 過去10回の衝突を記憶
- パターン認識で変化をつける
- 偶然性と予測可能性のバランス
```

## ✨ VISUAL HYPNOSIS - 視覚的催眠・ミニマル美学

### 1. **Particle Trail System**
```
- マーブルが发光するトレイルを残す
- トレイルは徐々にフェードアウト (3-5秒)
- 色は速度に応じて変化:
  - Slow: 青 (#4ECDC4)
  - Medium: 紫 (#A8A4CE)
  - Fast: 赤 (#FF6B6B)
- 数百個の粒子で構成
```

### 2. **Ripple Impact Effect**
```
- 衝突地点から波紋が広がる
- 波紋は同心円状に広がり、フェードアウト
- 色はモジュールタイプに応じて変化
- 2D + 3D のハイブリッド表現
```

### 3. **Breathing Light Animation**
```
- 全てのモジュールがゆっくり呼吸するように明滅
- 周期: 4-6秒 (人の呼吸に同期)
- 明度: 20% → 100% → 20%
- 衝突時に一瞬ハイライト (200%)
```

### 4. **Minimal Color Palette**
```
- 基調色: 深い藍色 (#0A0A0F)
- アクセント1: ターコイズ (#00BFA6) - 主要なフィードバック
- アクセント2: コーラル (#FF6B6B) - 重要なイベント
- アクセント3: ラベンダー (#A8A4CE) - まれな報酬
- ルール: 同時に使う色は3色まで
```

### 5. **Bloom & Glow System**
```
- Unreal Bloom Effect (Three.js)
- 衝突箇所が発光 (2-3秒持続)
- 周囲の環境光にも影響
- 蓄積エフェクト: 多くの衝突で全体的に明るく
```

## 🎯 THE "AH!" MOMENT - ピタゴラスイッチ的スッキリ感

### Core Concept: 完結した連鎖反応の美しさ

ピタゴラスイッチ（Pitagora Switch）の本質は、**「予測可能な連鎖が完璧に実行される喜び」**です。

### 1. **Sequence Completion Reward**
```
マーブルが最初のモジュールから最後まで到達した時:

■ 視覚的報酬:
  - 通過した全パスが金色に光る (1.5秒)
  - 完了マーク "✓" が各モジュールに表示
  - 最終地点から花火のような粒子エフェクト
  - カメラがゆっくりズームアウトして全体を俯瞰

■ 聴覚的報酬:
  - 完了和音 (Perfect Cadence: V → I)
  - 例: G7 (ドミソシ) → C (ドミソ)
  - 残響が長く伸びる (3-5秒)
  - 深い満足感を与える低音の終止

■ 心理的効果:
  - "YES!" という明確な完了通知
  - スマートフォンの振動 (1回短く)
  - シンプルなテキスト: "SEQUENCE COMPLETE"
```

### 2. **Predictable Path Visualization**
```
■ 配置時に予測線を表示:
  - マーブルの予想軌道を点線で可視化
  - 衝突するモジュールを順番にハイライト
  - 成功率をパーセンテージで表示 (87%, 92%, etc.)

■ 不確定要素の明示:
  - 予測が難しい箇所は "?" マーク
  - 複数の可能性がある場合は分岐表示
  - ユーザーは「どうなるか？」を想像できる

■ 実行と予測の比較:
  - 成功: "予想通り！" → 達成感
  - 失敗: "意外な展開！" → 驚き
  - いずれもポジティブな体験として設計
```

### 3. **The "Perfect Run" System**
```
■ 条件:
  - 全てのマーブルが失敗なくゴール到達
  - 1度も壁や床に触れない
  - 全てのモジュールが最低1回はトリガー

■ 報酬:
  - 画面全体が白くフラッシュ (0.2秒)
  - "PERFECT RUN!" の大文字表示
  - 特別な完了音 (オーケストラクレッシェンド)
  - スローモーションリプレイ (3秒)

■ 記録:
  - パーフェクト実行回数のカウンター
  - 最速クリアタイムの記録
  - 最多モジュール使用記録
  - これらを上書きした時の特別演出
```

### 4. **Step-by-Step Progress Feedback**
```
■ 各ステージの完了を明確に通知:
  - Stage 1完了: "1/5 COMPLETE"
  - Stage 2完了: "2/5 COMPLETE"
  - ...
  - Stage 5完了: "ALL COMPLETE!"

■ 進行状況バー:
  - 画面下部にシンプルなプログレスバー
  - 使用済みモジュールが点灯
  - 未使用モジュールは薄暗い

■ 残り距離の表示:
  - "あと3モジュールでゴール"
  - 数字がカウントダウン
  - "3... 2... 1... FINISH!"
```

### 5. **The "Clean Slate" Moment**
```
■ 全てのマーブルが消滅した瞬間:
  - 深い静寂 (2秒)
  - 画面が暗転
  - "CLEARED" のテキストがフェードイン
  - ゆっくりと新しいセットアップを促す

■ ユーザーが感じるべき感情:
  - "終わった" 達成感
  - "美しかった" 満足感
  - "またやりたい" 再挑戦欲

■ 自動クリーンアップ:
  - ボタン押さずに自動的にリセット
  - しかし、記憶は残す:
    - 前回の配置を保存
    - "RETRY?" プロンプト
    - "NEW LAYOUT?" 誘導
```

### 6. **Sukkir-sugi (Too Clean) Effect**
```
■ 完璧すぎる配置の時:
  - 全てのモジュールが幾何学的に整列
  - 全てのマーブルが同時にゴール

■ 特別演出:
  - 画面が分割され、各視点からリプレイ
  - スローモーション + 通常の同時表示
  - "MATHEMATICAL PERFECTION" のテキスト
  - 音は完璧な和音の重なり

■ 感情的効果:
  - "あまりに綺麗で涙が出る"
  - "これ以上はない" という感覚
```

### 7. **Micro-Completion Rewards**
```
■ 小さな達成も明確にフィードバック:
  - 1個のマーブルがゴール → 小さな "✓"
  - 3個連続 → "GOOD"
  - 5個連続 → "GREAT"
  - 全员成功 → "EXCELLENT"

■ 音による報酬:
  - 1個: 短い "チン"
  - 3個: "チン・チン・チン"
  - 5個: 5音のスケール
  - 全員: 完全な和音

■ 累積効果:
  - 小さな成功が積み重なり大きな達成感
  - "もっと欲しい" という中毒性
```

### 8. **The "Almost" Effect (あと一歩)**
```
■ ゴール直前で失敗した時:
  - "SO CLOSE!" の表示
  - スローモーションで失敗地点を再見
  - "RETRY?" ボタンを即座に表示

■ 心理的操作:
  - 失敗でもフラストレーションを減らす
  - "今度こそ!" という再挑戦意欲
  - 成功時の喜びを2倍にする

■ 援護機能:
  - "ヒントを見る?" ボタン
  - クリック1つで失敗箇所を修正
  - "パーフェクト実行" を試せる
```
